# `commodity`

`commodity` is an alias for [`currency`](./currency.md). It declares a
currency/commodity and accepts the same metadata, including `format-decimals`
for report display precision. Names are defined only once across both keywords.

Use whichever term is clearer for the unit being tracked; the loader and booking
system treat both keywords identically.

See the [`currency` / `commodity` syntax](../syntax.md#currency--commodity) and
[Currency](./currency.md).
